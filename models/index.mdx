Kimi K3, GLM 5.2, DeepSeek, Qwen, GPT, Claude, Gemini, and the rest of the Nito catalog are all available to you. No provider accounts, no keys, nothing to learn per provider. You name a model and Nito routes the call.

Switching costs nothing. Model names are stable, Nito maps each one to a backend that can run it, and moving between them changes nothing about how you work.

## The Privacy Level Comes with the Model

Every model carries a privacy level, and you get that level by choosing that model. There is no account-wide setting to remember and nothing to configure correctly: a throwaway prompt on a light model and a sensitive one on a Confidential model take the same command. The level can never quietly weaken. See [The Four Levels](/privacy/levels).

## Browsing and Choosing

Three commands, no config files.

- [`models`](/commands/choosing-a-model) browses the catalog for your account
- `model` sets a default you keep
- `--model` overrides it for one call

The catalog is live, so what you see when you browse is always current. None of it changes the model your harness runs.
